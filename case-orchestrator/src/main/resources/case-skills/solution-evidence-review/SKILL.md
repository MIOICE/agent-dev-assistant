# 方案证据检查方法

1. 事实结论必须能定位到当前客户和 MES 版本的来源 Chunk。
2. 资料冲突、版本不明或未检索到的内容单列为待确认事项，不能写成既定事实。
3. 涉及批量修改、删除、导出和敏感数据时，必须包含权限、审计、回滚与失败处理。
4. 测试计划覆盖正常、越权、重复提交、异常、边界数据量和回滚验证。
5. 客户沟通稿只描述确认后的业务范围与验收结果，不暴露内部表结构和安全细节。
